# «Ясно Бюро» — Сайт независимой веб-студии

Сайт авторского независимого бюро дизайна и разработки сайтов для малого бизнеса.

## Особенности проекта
- **Светлая редакционная эстетика:** тёплая бумага (`#FAF8F3`), крупная выверенная типографика (шрифт Manrope с поддержкой кириллицы), тонкие разделители (`#DCDDD3`), глубокий оливковый акцент (`#465C3B`), деликатный мягкий акцент (`#E5EBCF`).
- **Честный тон:** от первого лица, спокойный язык без клише («инновационные решения», «взрывной рост», гарантии первых мест в поиске).
- **Реальные проекты:** включены оптимизированные скриншоты реальных сайтов («Енисей-Спас», «ТалантЛэнд», «Икигай») в современных браузерных фреймах с WebP-сжатием.
- **Техническая надёжность:** чистый семантический HTML5, CSS-переменные (дизайн-токены), легковесный JavaScript без фреймворков и библиотек. Полная доступность контента при отключённом JS, поддержка `prefers-reduced-motion`, доступный аккордеон FAQ на `<details>`.

## Локальный запуск

Сайт является полностью статическим, его можно открыть прямо в браузере или запустить через локальный HTTP-сервер:

### Вариант 1 (Python):
```bash
python -m http.server 8000
```
И открыть в браузере: `http://localhost:8000/`

### Вариант 2 (Node.js):
```bash
npx serve .
```

### Вариант 3 (Любой браузер):
Дважды кликните по файлу `index.html`.

## Что нужно настроить перед публикацией:
1. **Имя основателя:**
   Замените `[ИМЯ]` в файлах `index.html` (секция «Обо мне») и `assets/js/main.js` (объект `YASNO_CONFIG.founder`).
2. **Контакт в Telegram:**
   Замените `[TELEGRAM]` в ссылках `https://t.me/[TELEGRAM]` в `index.html` и в объекте `YASNO_CONFIG.telegram`.
3. **Услуги и стоимость:**
   Цены и условия централизованно заданы в `assets/js/main.js` и в секции `#services` в `index.html`.
4. **Скриншоты проектов:**
   Реальные скриншоты сайтов уже захвачены и размещены в `assets/images/`:
   - `project-neftesbor.png` / `project-neftesbor.webp`
   - `project-talantland.png` / `project-talantland.webp`
   - `project-ikigai.png` / `project-ikigai.webp`
   При желании их можно обновить своими актуальными снимками экранов.
