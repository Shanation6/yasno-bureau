# «Ясно Бюро» — Сайт независимой веб-студии

Сайт авторского независимого бюро дизайна и разработки сайтов для малого бизнеса.

## Особенности проекта
- **Светлая редакционная эстетика:** тёплая бумага (`#FAF8F3`), крупная выверенная типографика (шрифт Manrope с поддержкой кириллицы), тонкие разделители (`#DCDDD3`), глубокий оливковый акцент (`#465C3B`), деликатный мягкий акцент (`#E5EBCF`).
- **Честный тон:** от первого лица, спокойный язык без клише («инновационные решения», «взрывной рост», гарантии первых мест в поиске).
- **Реальные проекты:** включены оптимизированные скриншоты реальных сайтов («Енисей-Спас», «ТалантЛэнд», «Икигай») в современных браузерных фреймах с WebP-сжатием.
- **Техническая надёжность:** чистый семантический HTML5, CSS-переменные (дизайн-токены), легковесный JavaScript без фреймворков и библиотек. Полная доступность контента при отключённом JS, поддержка `prefers-reduced-motion`, доступный аккордеон FAQ на `<details>`.

## Разработка и сборка

### Вариант 1 (Vite / npm — рекомендуется для продакшена):
```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера с горячей перезагрузкой
npm run dev

# Продакшен-сборка (минификация HTML/CSS/JS, хеширование ассетов в dist/)
npm run build

# Предпросмотр собранной версии
npm run preview
```

### Вариант 2 (Без сборки / Статический запуск):
Сайт можно запускать и напрямую без сборки:
- **Node.js**: `npx serve .`
- **Python**: `python -m http.server 8000` (открыть `http://localhost:8000/`)
- **Браузер**: открыть файл `index.html` через любой локальный веб-сервер.
